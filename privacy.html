Privacy policy

MomentVault Local is a personal application installed on its owner’s Windows PC. This policy describes that installation and the public information website.

The application uses YouTube API Services. Use of its YouTube features is subject to the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

1. Data access and purposes

Google authorization allows the application to upload videos and metadata to the chosen channel, confirm that channel’s identity, and read statistics and analytics for the owner’s videos. Requested scopes are youtube.upload, youtube.readonly and yt-analytics.readonly. These permissions do not include Gmail, Drive, contacts or payments.

Uploads include the video file, title, description, publication setting and paid-promotion declaration. The destination channel ID is checked before publishing.

For videos managed by the application, it may retrieve view counts, publication dates, privacy status and daily analytics such as engaged views, watch time, average view duration or percentage, likes, comments and shares. It stores aggregate counts rather than individual comments, viewer identities or private messages.

Before editing, it may search for public videos and channels related to a subject or moment. Results may include titles, descriptions, IDs, publication dates, durations and public counts, plus a sample of recent channel uploads. Search terms are sent to YouTube. These results inform research and do not grant permission to reuse another creator’s footage.

A view-count observation near the first 24 hours is dated. Daily reports, public cumulative views and campaign-approved paid views are different measurements.

Using statistics to update the editing controller or generate analytical hypotheses is a separate purpose, disabled until its permitted basis is documented. Connecting the channel does not enable that use or start production. Producer-model weights remain fixed.

2. Storage and processing

OAuth credentials and tokens are stored locally using Windows account-bound DPAPI protection. The application does not request or store the Google account password.

The local queue, editing recipes, publication references, counts, reports and controller state are stored on disk with a managed backup. Those history files are not encrypted by the application. Source media, transcripts, frames and rendered videos also remain on the PC.

The local engine listens on the PC’s loopback address. It uses a local HttpOnly session cookie and protections against requests from other origins. Other software with access to the same Windows account may access local files. External backups are controlled by the owner.

Transcription, visual analysis and model processing run locally. The application does not send media or reports to an online inference service.

3. Destinations and sharing

Authorization, uploads, searches and statistics requests use Google and YouTube services over the internet. When an authorized campaign submission is enabled, the application sends the public video URL to that campaign platform. Campaign authentication uses a separate local browser profile.

The application does not sell Google user data, add third-party advertising to the local interface, or embed a YouTube player there. Its use of Google user data is limited to the practices disclosed in this policy and the applicable Google API Services User Data Policy, including its Limited Use requirements.

4. Retention and deletion

Public research results may be reused from cache for up to six hours. Stored API research data is removed from the managed state and backup after 30 days, or through the deletion and disconnection controls.

While the engine is running, including during a production pause, it attempts to reconfirm channel access daily and video availability/access every 29 days. A transient access failure pauses production and is retried within an hour. Detected revocation, or 30 days without confirmation, triggers local deletion of the managed YouTube data. If the PC is off, maintenance resumes when the engine runs again.

Missing access or a missed measurement window is not treated as zero views. The application does not claim to delete backups made outside its control.

5. Your controls

In the local application, open Tarefas → Shorts → Configurar YouTube to use the data controls:

  • Delete measurements and reset learning: removes stored counts, reports, analyses and learned controller parameters from the managed state and backup. Original media, local exports and publication references are preserved.
  • Disconnect and delete local YouTube data: pauses production, waits for active work, removes API data and tokens, resets the controller and attempts to revoke the Google token. Local media files and videos already on YouTube remain. The OAuth client configuration is retained.

You can also revoke the application’s access in your Google account. Use YouTube Studio to manage videos already published. Disconnecting locally does not delete remote videos.

6. This public website

This is a static information site hosted on GitHub Pages. It has no sign-in form, application analytics script, video upload or access to the desktop installation. GitHub Pages logs and stores visitor IP addresses for security purposes. The provider processes connection data under the GitHub Privacy Statement.

7. Operator and questions

The installation is operated by its account holder for the MomentVault channel. It is for personal owner use and has no public account registration. The owner can inspect or delete data through the controls above and request maintenance through the original support chat used to build the installation.

Do not send passwords, tokens or OAuth client files through a public channel. Changes to purposes or permissions require information and authorization before use.
